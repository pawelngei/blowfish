{{/* Returns alt text for a page's featured image. Chain: the page's own `alt` front matter, then its `description`, then (unless "fallbackTitle" false) its title. The title is a last resort for rendered tags only - an empty alt marks an image decorative and assistive tech skips it entirely, which is worse than a title. Metadata callers (og:image:alt, schema.org) pass "fallbackTitle" false and emit nothing when the result is empty, since og:title / schema `name` already carry the title and repeating it there adds no information. When the page has no featured image of its own but borrows one from another bundle through `images` (e.g. a seed tile showing an art piece), the alt describes the image actually displayed, so the owning page's alt or description wins. That page's *title* does not - the tile links to this page, not to the artwork. Takes (dict "page" $page ["fallbackTitle" false]); returns a string. */}} {{ $page := .page }} {{ $useTitle := true }} {{ if isset . "fallbackTitle" }}{{ $useTitle = .fallbackTitle }}{{ end }} {{ $source := $page }} {{/* Same resolution order as article-link/card.html, so the alt cannot describe an image other than the one the caller renders. */}} {{ $own := ($page.Resources.ByType "image").GetMatch "*feature*" }} {{ if not $own }}{{ $own = ($page.Resources.ByType "image").GetMatch "{*cover*,*thumbnail*}" }}{{ end }} {{ if not $own }} {{ with $page.Params.images }} {{ $imagePath := index . 0 }} {{ if not (or (strings.HasPrefix $imagePath "http://") (strings.HasPrefix $imagePath "https://")) }} {{ with $page.File }} {{ $targetDir := path.Dir (path.Join .Dir $imagePath) }} {{ with site.GetPage $targetDir }} {{ if or .Params.alt .Description }}{{ $source = . }}{{ end }} {{ end }} {{ end }} {{ end }} {{ end }} {{ end }} {{ $alt := "" }} {{ with $source.Params.alt }}{{ $alt = . }}{{ end }} {{ if not $alt }}{{ with $source.Description }}{{ $alt = . }}{{ end }}{{ end }} {{ if and (not $alt) $useTitle }}{{ $alt = $source.Title }}{{ end }} {{ return $alt }}
